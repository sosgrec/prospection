# Fonctionnalités

Ce que fait l'appli, écran par écran. La colonne **Arrivée** donne la version où la fonction est apparue. Tout ce qui existait le 19/11/2026 est noté « avant 1.0.0 », avec la date du commit qui l'a apporté ; à partir de 1.0.0, on note le numéro de version.

Un fil Évo met ce document à jour dans la même demande de fusion que le code : il ajoute la ligne, et l'arrivée « à venir » devient le numéro de version au moment du « En prod ».
